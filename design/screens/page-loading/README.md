# وضعیت بارگذاری ناقص

تصاویر Chromium محلی، عرض‌های ۳۹۰ و ۱۴۴۰، تم تاریک. HTML از قالب واقعی Django
و اطلاعات مقصد نمونه است؛ پاسخ API عمداً بیش از پانزده ثانیه معطل شده است.
عنوان و اطلاعات اولیه باقی می‌مانند و پیام رفرش دستی نمایش داده می‌شود.
این تصاویر مرجع وضعیت انتظارند؛ دادهٔ هواشناسی production یا redesign صفحات
نیستند. جزئیات بررسی در `docs/page-loading.md` آمده است.
