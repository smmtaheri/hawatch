# اصلاح نمایش جزئیات تخصصی

این تصاویر از renderer واقعی forecast-v5 در مرورگر Chrome و صفحهٔ fixture محلی
گرفته شده‌اند؛ پیش‌بینی‌ها synthetic هستند و درخواست شبکه یا دادهٔ کاربر ندارند.
هر تصویر بعد از بازشدن جزئیات تخصصی و پیش از هر اسکرول افقی ثبت شده است.

- `desktop-dark.png`: دسکتاپ ۱۴۴۰px؛ هر سه وضعیت شاخص گرما در نمای کامل دیده
  می‌شود.
- `mobile-dark.png`: موبایل ۳۹۰px؛ برچسب‌های ردیف‌ها و وضعیت «داده ناقص»/مقدار
  قابل‌محاسبه داخل viewport قابل مشاهده‌اند.
- `../..` تصاویر مرجع قبلی دست‌نخورده‌اند.

برای بازسازی محلی، Vite را روی `127.0.0.1:5173` اجرا کنید و
`apps/web/tests/visual/forecast-specialist.html` را با Chrome باز کنید. خود فایل
در مسیر `tests/` است و وارد bundle انتشار نمی‌شود.
