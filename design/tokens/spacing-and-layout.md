# فاصله و layout

مقیاس پایهٔ فاصله ۴px است. فاصله‌ها باید از مقیاس مشترک استفاده کنند تا صفحه‌ها منسجم بمانند: ۴، ۸، ۱۲، ۱۶، ۲۰، ۲۴، ۳۲، ۴۰ و ۴۸px.

## قواعد کلی

- `direction: rtl` در ریشهٔ صفحه و در تمام flowهای متنی برقرار است.
- content در web حداکثر حدود ۱۵۰۰px عرض دارد و در اطراف آن فضای تنفس باقی می‌ماند.
- کارت معمولی radius حدود ۱۸px و hero radius حدود ۲۴px دارد.
- فاصلهٔ بین sectionها از فاصلهٔ داخلی کارت‌ها بزرگ‌تر باشد.
- border ظریف و shadow نرم‌اند؛ depth نباید صفحه را شلوغ کند.
- gridها باید `minmax(0, 1fr)` یا معادل امن داشته باشند تا محتوای فارسی باعث overflow نشود.
- هر نوار افقی قابل اسکرول باید درون container خودش محدود شود؛ overflow افقی کل صفحه ممنوع است.

## responsive

تصاویر مرجع mobile عرض ۵۷۶px و تصاویر web عرض ۱۹۰۵px دارند. در mobile، ترتیب و تراکم اطلاعات از صرفاً کوچک‌کردن desktop مهم‌تر است.

- Home: search input و دکمهٔ جست‌وجو نباید روی هم بیفتند.
- Destination: روزها قبل از کنترل هوا بیایند؛ مسیرها دو ستونه و کوچک باشند.
- Route: ساعت و سرعت در یک ردیف جمع‌وجور باشند؛ جداکنندهٔ عمودی حذف شود.
- برای کارت‌ها و داده‌های ساعتی، کاهش padding و اندازهٔ type مجاز است، اما hit area و خوانایی نباید قربانی شود.
