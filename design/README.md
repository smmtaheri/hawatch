# طراحی جاری هواچ

- [سیستم طراحی](system/design-system.md): سیستم قبلی سایت، همراه با چیدمان تأییدشدهٔ پیش‌بینی هفتگی.
- [توکن‌ها](tokens/visual-tokens.json): مقادیر جاری رنگ، سطح، فونت و هندسه.
- [گالری اجرای جاری](screens/current/index.html): شش صفحه در دو تم، موبایل و دسکتاپ.
- [بررسی جاری](../docs/new-design-qa.md): حدود و نتیجهٔ اعتبارسنجی.

`source-screens/`، تصاویر اصلی `screens/new-design/` و `screens/forecast-v5/reference/` منابع تحویل‌اند و دست‌نخورده حفظ می‌شوند؛ ظاهر جاری را گالری جاری مشخص می‌کند. فایل‌ها و مستندات اختصاصی Login تغییر نکرده‌اند. خروجی‌های اجرای قدیمی و راهنماهای متعارض حذف شده‌اند.
