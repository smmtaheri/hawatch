# مرجع طراحی پیش‌بینی v5

این پوشه مستندات لازمِ بستهٔ تحویل v5 را نگه می‌دارد. قواعد اجرای مورد توافق و قرارداد API واقعی در [پیش‌بینی هفته](../../week-forecast.md) و نتیجهٔ بررسی در [گزارش QA](../../week-forecast-qa.md) مرجع‌اند. نمونه‌های زمان‌بندی، لینک اشتراک، تجهیزات و فونت در اسناد تحویل، تصمیم‌های بعدی محصول را جایگزین نمی‌کنند.

- [راهنمای فرانت HTML](frontend-guide.html) و [راهنمای اجرای بسته](IMPLEMENTATION-fa.md)
- [قرارداد داده](DATA-fa.md)، [اشتراک](SHARING-fa.md) و [معیار تحویل](ACCEPTANCE-fa.md)
- [گالری تصاویر مرجع](../../../design/screens/forecast-v5/reference/index.html)
- [نگاشت دارایی‌های اصلی و SHA-256](asset-locations.json)

کد تطبیق‌داده‌شدهٔ فرانت در `apps/web/src/features/week/` و دارایی‌های مصرفی سایت در `apps/web/public/new-design/` هستند. تصاویر حالت‌ها در `design/screens/forecast-v5/reference/` و منابع بصری صرفاً مرجع، از جمله تصاویر تجهیزات و نمونه‌های خروجی، در `design/assets/forecast-v5/` نگه‌داری شده‌اند؛ این پوشه‌ها وارد build یا دانلود کاربر نمی‌شوند. فایل فونت و تصاویر اصلی تبدیل نشده‌اند و فایل OFL حفظ شده است.

مسیرهای `reference/site/`، `tools/` و `assets/` در راهنماهای اصلی به بستهٔ تحویل اشاره دارند. کپی سایت دمو، دادهٔ ساختگی، ابزارهای تولید همان بسته، گزارش‌های تکراری و HTMLهای تکراری حذف شده‌اند. برای مکان فعلی هر تصویر، از نگاشت بالا استفاده کنید. کاتالوگ تجهیزات در این پوشه صرفاً مرجع تصویر و انتساب است؛ منطق پیشنهاد تجهیزات از بک‌اند واقعی می‌آید.

پوشهٔ ریشهٔ `new-design/` و `new-design.zip` بستهٔ قدیمی بودند و حذف شدند. مسیر هم‌نام در `apps/web/public/` مصرفی و فعال است.
