# پیش‌بینی هفته و منابع طراحی

مرجع ظاهر جاری [سیستم طراحی](../../../design/system/design-system.md)، [توکن‌ها](../../../design/tokens/visual-tokens.json) و [گالری اجرای جاری](../../../design/screens/current/index.html) است. سیستم سطح و رنگ نسخهٔ قبلی سایت مبناست؛ v5 نمایش پیوستهٔ روزها و هندسهٔ تأییدشدهٔ هفته را نگه می‌دارد. راهنماها، قراردادهای نمونه و توکن‌های قدیمیِ متعارض حذف شده‌اند.

رفتار و API واقعی در [پیش‌بینی هفته](../../week-forecast.md) و بررسی جاری در [QA طراحی](../../new-design-qa.md) هستند. بستهٔ اولیه یا نمونهٔ طراحی مرجع محاسبهٔ زمان، تجهیزات یا دسترسی نیست.

تصاویر اصلی در `design/screens/forecast-v5/reference/` و `design/screens/new-design/` بدون تبدیل حفظ شده‌اند؛ [گالری تحویل](../../../design/screens/forecast-v5/reference/index.html) فقط منبع اولیه است. `state-matrix.json` شناسهٔ همین تصاویر را نگه می‌دارد و قرارداد ظاهر جاری نیست. دارایی‌های مصرفی در `apps/web/public/new-design/` و دارایی‌های صرفاً مرجع در `design/assets/forecast-v5/` هستند.

[نگاشت و SHA-256 دارایی‌ها](asset-locations.json)، `source-provenance.json` و اسناد انتساب تجهیزات برای ردیابی و مجوز حفظ می‌شوند. تصاویر، فونت‌ها، OFL و فایل‌های اختصاصی Login حذف یا تبدیل نشده‌اند.
