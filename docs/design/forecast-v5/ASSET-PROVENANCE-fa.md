# ردیابی دارایی‌های اصلی

فایل‌های مصرفی سایت در `apps/web/public/new-design/` هستند؛ منابع صرفاً بصری در `design/assets/forecast-v5/` و تصاویر تحویل در `design/screens/forecast-v5/reference/` حفظ می‌شوند. `asset-locations.json` مسیر و SHA-256 اصلی و `source-provenance.json` انتساب بستهٔ تحویل را نگه می‌دارند.

هشت عکس پس‌زمینه، عکس‌های خروجی اشتراک، فونت Vazirmatn، Estedad/OFL و تصاویر اصلی تغییر bytes ندارند. تناژ عکس مسیر فقط با CSS تنظیم می‌شود. فایل‌های مجوز و اسناد انتساب تجهیزات حفظ می‌شوند.

توکن و راهنمای اجرای بستهٔ قدیمی مرجع محصول نیستند؛ ظاهر جاری فقط از [سیستم طراحی](../../../design/system/design-system.md) و [توکن‌ها](../../../design/tokens/visual-tokens.json) می‌آید.
