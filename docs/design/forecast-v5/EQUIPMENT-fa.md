# تجهیزات پیشنهادی و تصاویر مرجع

۳۵ نمونهٔ واقعی جست‌وجوشده در `equipment/photos/` قرار دارد؛ فهرست دقیق، URL صفحه، URL تصویر، ابعاد، SHA-256 و تاریخ دریافت در `equipment/catalog.json` ثبت است. دادهٔ خام نتایج نیز داخل `equipment/references/` قرار دارد. `equipment/ATTRIBUTION-fa.md` وضعیت حقوق هر نمونه را بیان می‌کند؛ مجوز عمومی برای این عکس‌های تجاری احراز نشده است. تصاویر بدون دستکاری ذخیره شده‌اند و صرفاً برای مرجع طراحی‌اند. استفادهٔ عمومی نیازمند مجوز یا جایگزین مناسب است؛ خود UI از SVG خطی مستقل استفاده می‌کند.

وسایل شامل عینک آفتابی/کولاک، کلاه، باف، ضدآفتاب، لایهٔ اول/پلار/کاپشن پر/ضدآب/بادگیر، دستکش لایهٔ اول/گرم/پر/ضدآب، کفش/جوراب/گتر، باتوم، هدلامپ، کوله/کاور/کیسهٔ ضدآب، بطری/فلاسک/فیلتر، کمک اولیه/پتوی نجات/جهت‌یابی/پاوربانک، یخ‌شکن/کرامپون/کلنگ و خوراکی‌اند. دستکش پر از نمونهٔ واقعی Rab Expedition 8000 انتخاب شده و با دستکش صرفاً عایق مصنوعی یکی نیست.

نمونهٔ UI برای بهار، تابستان، پاییز، زمستان، باران، باد، برف، یخ و تجهیزات عمومی در `screens/components/` است. دادهٔ `gearSets` صرفاً پوشش حالت‌های طراحی است؛ recommendation engine واقعی باید به فصل/باد/بارش/زمان/ارتفاع/شرایط مسیر و تجربهٔ کاربر متصل شود. هر وسیله نام + دلیل کوتاه دارد. ابزار یخ با توجه به نوع مسیر، کفش سازگار و مهارت پیشنهاد شود؛ فهرست عمومی نشان‌دهندهٔ نیاز قطعی یک مسیر نیست.

در مسیر disclosure زیر خلاصه، حالت پیش‌فرض بسته؛ بازشدن شبکهٔ بی‌کادر از آیکون، نام و دلیل. عکس‌های برند در صفحهٔ اصلی استفاده نشوند تا UI سنگین و ناهماهنگ نشود. اگر یک وسیله در چند شرط ظاهر شد، id یکسان را deduplicate کنید؛ همهٔ آیکون‌ها از همان فایل مرجع باشند.
