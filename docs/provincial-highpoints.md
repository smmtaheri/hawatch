# استاندارد مقصدهای بام استان‌ها

این سند معیار canonical کاتالوگ برای مقصدهای «بام استان» است. هر استان فقط یک
صفحهٔ canonical برای قلهٔ انتخاب‌شده دارد؛ نام‌های رایجِ همان قله در `aliases`
می‌آیند و برای قله‌های متفاوت صفحهٔ تکراری یا alias ساختگی ایجاد نمی‌شود.

| استان | مقصد canonical هواچ | وضعیت نام‌های نزدیک |
| --- | --- | --- |
| آذربایجان غربی | قلهٔ اورین (`orin`) | بوزقوش بدون اثبات هویت/مختصات مشترک alias اورین نمی‌شود. |
| بوشهر | قلهٔ بیرمی (`beyrami`) | پازنان نام رایج همین قله است و alias آن است. |
| خراسان جنوبی | قلهٔ نایبند (`nayband`) | باقران بدون اثبات هویت/مختصات مشترک alias نایبند نمی‌شود. |
| گلستان | قلهٔ گاوکشان (`gavkoshan`) | قلعه‌ماران/شاخک شاهوار بدون اثبات هویت مشترک alias نمی‌شود؛ منطقهٔ گاوکشان مرز گلستان و سمنان ثبت شده است. |
| مرکزی | قلهٔ دومیر (`domir`) | شهباز بدون اثبات هویت/مختصات مشترک alias دومیر نمی‌شود. |
| هرمزگان | قلهٔ تشگر/هماگ (`tashger`) | گنو و بشاگرد بدون اثبات هویت مشترک alias تشگر نمی‌شوند. |
| کردستان | قلهٔ قولی‌زلیخا (`qoli-zolikhah`) | چهل‌چشمه نام رایج همین مجموعه است؛ آبیدر بدون اثبات هویت مشترک alias نمی‌شود. |

این تصمیم‌ها از تغییر slug یا ساخت URL موازی جلوگیری می‌کنند و برای اختلاف‌های
جغرافیاییِ واقعی، امکان افزودن مقصد مستقل در آینده را باز می‌گذارند.
