# Flow: برنامه‌ریزی مسیر

```text
Route
  → انتخاب روز
  → انتخاب بامداد/صبح/ظهر/شب
  → تنظیم ساعت شروع
  → انتخاب سرعت حرکت
  → محاسبهٔ زمان عبور از نقاط
  → نمایش weather هر نقطه و کارت تصمیم
  → اصلاح زمان/سرعت یا اشتراک‌گذاری
```

## invariants

- تغییر ساعت شروع باید زمان رسیدن همهٔ نقاط را هماهنگ تغییر دهد.
- تغییر سرعت باید duration و arrival time را تغییر دهد، نه identity نقاط را.
- period باید روی forecast و point weather یکسان اثر کند.
- هشدار critical باید در point، hourly card و decision summary سازگار بماند.

## خروجی تصمیم

کارت تصمیم باید حداقل زمان شروع، زمان رسیدن، نقطهٔ حساس، زمان آن و پیشنهاد قابل اقدام را بگوید. اگر داده stale یا partial است، قطعیت متن کاهش یابد.
