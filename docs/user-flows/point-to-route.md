# Flow: Point تا Route

```text
Point
  → انتخاب مسیر از بخش «مسیرها»
  → Route با نقطه parent و route slug
  → مشاهدهٔ نقاط مسیر و وضعیت هوا
```

مسیر انتخابی باید از نظر نام، origin و point برای کاربر واضح باشد. Route باید امکان برگشت مستقیم به Point و انتخاب مسیر دیگر همان نقطه را حفظ کند.

اگر route data ناقص باشد، catalog route و علت نقص جدا نمایش داده شوند؛ صفحه نباید با دادهٔ ساختگی تصمیم قطعی بسازد.
